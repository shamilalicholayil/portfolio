# Frontend Field Notes — Design Plan

## Surface
**Experience**, with a secondary persuasive function. The visitor should encounter the work immediately; the interface supports the evidence instead of resembling a startup landing page.

## Audience and job
Recruiters, hiring managers, and collaborators should understand who Shamil is, inspect two real products, see concrete engineering scope, and reach him directly.

## Thesis
A concise editorial record of full-stack products Shamil has built. Warm paper, large serif headlines, technical monospace annotations, and one vermilion build line create the identity.

## Composition
1. Compact nameplate and navigation.
2. Asymmetric portrait-led hero with factual positioning.
3. Two full-width project chapters: GadgetHub and HireReady.
4. Capability ledger tied to work rather than skill ratings.
5. Short profile and direct contact block.

## Visual system
- Paper `#F3F0E8`
- Surface `#FAF8F2`
- Ink `#171714`
- Muted `#5F5D55`
- Rules `#CFC9BC`
- Vermilion `#C64F2F`
- Dark stage `#24231F`
- Display: Newsreader
- Body: IBM Plex Sans
- Metadata: IBM Plex Mono

## Signature element
A continuous vermilion build line joins project markers 01 and 02 and guides scanning through the work.

## Content rules
- Only claims verified from public project repositories and live sites.
- No fake metrics, testimonials, service cards, skill percentages, placeholder contact data, or inert form.
- Every project includes a real screenshot, scope, stack, live link, and source link.

## Responsive behavior
Desktop uses a 12-column editorial composition. Tablet reduces to balanced columns. Mobile moves the portrait directly after the hero statement, shifts the build line to the left edge, keeps project visuals wide, and exposes a keyboard-accessible disclosure menu.

## Motion and accessibility
Only restrained image scale on hover and navigation state changes. Reduced-motion removes transitions. Semantic structure, visible focus, 44px targets, meaningful alt text, and relative paths support accessibility and GitHub Pages deployment.

## Slop audit
Target score: **0/10**. No tech gradient, generic tech hue, feature-tile grid, accent rails, blur panels, monument stats, icon toppers, center stack, default typography, or wrong-surface composition.
